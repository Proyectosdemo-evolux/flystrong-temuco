# Flystrong Temuco

Demo funcional (datos ficticios) de la web comercial, el portal del alumno y el panel administrativo.

Stack: Next.js 16 · React 19 · TypeScript · Tailwind 4. Próximo: PostgreSQL + Drizzle.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Rutas: `/` web comercial · `/portal` alumno · `/admin` administración.
